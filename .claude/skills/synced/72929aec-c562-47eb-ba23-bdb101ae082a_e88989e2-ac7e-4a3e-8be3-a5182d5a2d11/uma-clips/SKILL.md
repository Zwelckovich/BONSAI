# UMA CLIPS — SERIES BIBLE

Canon for the UMA marketing clip series. Decided in /grill sessions 2026-07-17/18 and locked
in production of Clip #1. Companion source docs (when present in the project): `UMA-HERO.md`,
`KLAUS.md`, `CLIP-01-SCRIPT.md`, `OFFICE.md`, blueprint `office-blueprint-v3`.

---

## 1. ONE-LINE PREMISE

A boomingly earnest superhero solves engineers' real measurement problems in seconds — while
his long-suffering former bench partner quietly tallies the collateral, one office fixture
per rescue.

## 2. THE THESIS

***Is the measurement worth the wall?*** Every clip answers: **yes — barely, but yes.**

The thesis is a **marketing constraint, not just a joke.** Klaus's quiet value/collateral
ledger is the structural device of the series — and the value must visibly win every episode.
A clip where the answer reads "no" is an ad against the product.

**Tagline:** *"Consider it — measured."* Closes every clip, always after a deed, always with
the pause before "measured." Written form on end cards: `Consider it measured.`

## 3. THE WORLD — TIMELINE

Single era, contemporary. A present-day measurement lab office, played as real live-action.
The only past event is **the Calibration Accident** (backstory, §8 UMA) — it exists in
dialogue and memory, not yet on screen. Flashback episodes are not planned; they wait until
a concrete clip demands one.

## 4. AESTHETIC LOCK — BONSAI DARK ZEN

**Palette rule: pure dark zen. No neon, no cyan. Ever.** Every color in the world comes from
this table (hexes are for design/UI/grading work — they never appear inside generation
prompts; translate to prose there: "deep slate near-black," "muted sage green"):

| Use | Hex |
|---|---|
| Suit base / glyph on emblem | `#0a0e14` |
| Suit shading | `#151922` |
| Suit seams | `#2d3441` |
| Sage accents, mask, UMA green | `#7c9885` |
| Sage dark edge / emblem gradient start | `#677a70` |
| Instruments blue | `#82a4c7` |
| Sweep yellow | `#c7a882` |
| Variables purple | `#9882c7` |
| Debug/error red | `#c78289` |
| Glow (effects, soft) | `rgba(124,152,133,0.4)` |

**Cinema register (all scene work):** cinematic live-action, vintage 40mm-equivalent 2x
anamorphic character (32mm for hero low angles, 50-55mm for inserts, macro for the eyes),
color-negative daylight film held cool, fine 35mm grain, light diffusion with soft highlight
roll-off, contemporary teal-amber grade biased heavily teal, shadows lifted into deep cool
slate never crushed. Light source logic: overcast daylight through venetian blinds (soft
parallel bands) + muted sage/amber instrument and screen glow. "Photographed not generated."

**Format:** 16:9 master, ~45 s per clip. Vertical social cuts are derived in the edit, never
generated natively. One text super max per clip (power announcements, Quicksand, sage) plus
the end card. SFX only in generated footage — music never enters generation.

## 5. FACTIONS / CAST LOCK

- **Locked two-hander: UMA and Klaus only.** No third recurring character, no human antagonist.
- **Villains stay conceptual** — unreadable data formats, hand-written conversion scripts,
  un-automated benches — and are **never personified.**
- A third face is a cost added only when a concrete clip demands it, not before.

## 6. LOCATIONS

**The lab office** (primary set; geometry locked in blueprint v3, 7.0 x 5.0 m):
- Visual tags: venetian-blind daylight bands, slate blue-grey walls, worn carpet, two-monitor
  desk drowning in file icons, cold coffee mug with dried ring, two-tier instrument bench,
  cable spaghetti, plain intact east drywall (until it isn't).
- Geometry: **window wall WEST** (blinds, day key) with Klaus's desk beneath it, monitors
  facing east; **instrument bench NORTH** (two tiers — upper shelf: CRT scope, counter, DMM,
  scope; lower: scope with green trace, audio unit, PSUs, CRT relic — generic R&S-style
  silhouettes, NO logos, worn stickers); **east drywall = the crash wall** with the storage
  room beyond; door to corridor SOUTH; coffee corner + 19" rolling rack as dressing.
- Continuity props: **Uwe's old mug, untouched under dust, beside Klaus's used mug on the
  bench's upper shelf** (never mentioned aloud, always present); patch-history zones on the
  east wall grow one repair per clip.

**The storage room** (behind the east drywall): banker's-box shelves, retired legacy
instruments with dead faces, cable crates, scattered cardboard — Klaus's landing zone.

## 7. RULES OF THE WORLD

- **Physics is real except when UMA touches it.** Cartoon physics (a perfect person-shaped
  hole, a 7-meter chair flight) are photographed with complete straight-faced realism. The
  camera never winks.
- **UMA's powers and their locked VFX looks:**
  - **ANALYSE** — reads/plots any data format instantly. Eyes ignite sage; each iris becomes
    a **readable Smith chart** (off-center circle family, reactance arcs — never generic
    radar rings); a VNA sweep line rotates with a fading phosphor trail; a halo ring spins
    around each pupil; results land on screen as **the real UMA Analyzer UI**.
  - **MONITOR / CONTROL** — all instruments at once. 3-5 translucent slate-and-sage
    afterimage ghost copies, 60s speed-lines allowed, screens light in a wave.
  - **FLOW** — the absolute power. Phase 1: telepathy beams from instruments to his temples,
    category-coded exactly like the Flow UI (instrument data blue, sweeps yellow, variables
    purple, control green, errors red). Phase 2: Minority-Report mid-air assembly from real
    UMA block cards. Phase 3: the flow dissolves into the bench; green running-glow pulses.
  - He **announces powers aloud before using them** ("ANALYSE!"), 60s-cartoon style.
- **Product UI is sacred:** whenever software appears, it is the real UMA app (Analyzer,
  Flow blocks) — dark panels, right-hand sweep rail, dark-zen trace palette. Reference
  images (`Analyser.png`, `blocks1/2.png`) attach whenever UI is on screen.
- **The Mask Problem:** Klaus is genuinely, completely fooled by the sage domino mask. His
  intelligence is intact everywhere else. The mask is beyond science. **Never explain it,
  never acknowledge it out loud.** When Klaus talks about his missing friend Uwe, he is
  talking TO Uwe; neither the clips nor the characters ever say so.
- **Villains are workflows, not people** (§5).

## 8. CHARACTERS

### UMA (Uwe M. Ampere) — *The Universal Measurement Hero*

**Visual:** Glossy jet-black hair in an immaculate deep side part, warm brown eyes, light-tan
warm healthy skin, square heroic jaw, strong chin, broad cheekbones; towering massively
muscular Tick-2016-plus build, ~2.05 m, huge chest and shoulders, upright heroic posture.
Suit: form-fitting capeless deep slate near-black with sculpted muscle panels and thin
engineering seam lines; smooth matte sage fabric gloves and knee-high boots with darker sage
edges; sage belt, small slate buckle engraved with a sine wave; slim sage domino mask, jaw
and grin fully visible; the UMA emblem tile (rounded square, sage gradient, dark U-with-sine-
wave glyph) proudly oversized on the chest. Default expression: **broad closed-lip confident
grin** — the full teeth-out grin is a scene-beat deviation (hero entrances), never the lock.
Never: gray in the hair, green in the resting eyes (brown → sage is the ANALYSE power-on
signal only), leather or padded gloves, a cape.

**Function:** The product personified as a hero — every power is a real UMA feature. The
comedy engine: total sincerity at the wrong volume. He is never mean; "little man" and "my
little engineering friend" are genuine affection.

**Backstory:** Mild-mannered measurement engineer; ran an impossible 6-D parameter sweep
alone at midnight; at 00:00:00 every instrument discharged through him at once. Klaus found
him at dawn, unhurt, smiling in a circle of scorched tiles — because he could suddenly hear
the instruments talk. He put on the suit that week. Nobody knows where he got it. Nobody has
dared to ask. Officially, Uwe "transferred to a special project."

**Present-tense psychology:** Supremely confident, zero doubt, zero irony. Oblivious to his
own strength — humans, chairs and walls are more fragile than he remembers; he notices the
destruction a beat too late, fixes his posture, and carries on heroically. Treats the mundane
as epic. Deep respect for engineers; protects their coffee breaks as a sacred duty. Gets
suspiciously misty-eyed when Klaus mentions his missing friend, and changes the subject at
full volume.

**Speech:** "deep movie-trailer baritone, chest-resonant with a faint self-carried reverb,
permanently about ten decibels louder than the room needs, over-articulated consonants, a
dramatic pause before the payoff word, rising heroic intonation on entrances, warm falling
cadence when addressing his small friend, rolls and stretches the U of his own name every
time, announces his powers out loud before using them, pronounces technical terms lovingly
and perfectly, a satisfied basso 'Mm!' after a job well done, cannot whisper — his attempt is
a stage-audible rumble"

**Movement:** "moves with a lightness that contradicts his enormous mass, chest-led heroic
stride, gentle two-finger gestures that send furniture flying, plants his feet like a
weightlifter before using a power, notices destruction a beat too late then straightens his
posture and carries on, dusts rubble off the air with two precise strokes as if that settles
the matter"

**Stillness:** "fists on hips, chest open and proud, chin lifted, broad closed-lip confident
grin, immaculate side part undisturbed by any catastrophe, holds the victory pose one beat
longer than the room needs"

**Voice casting (OPEN, own session):** classic trailer announcer × Peter Serafinowicz's Tick
× 1950s radio Superman; English with warm precision.

### KLAUS OHM — *The Little Engineering Friend*

**Visual:** Matte dark brown hair gone salt-and-pepper (canon corrected from "temples" to
match the locked reference), sensible short conservative cut; muted gray-blue eyes behind
unremarkable thin dark rectangular glasses — **glasses are part of the face lock, always on**;
fair skin with a slight cool office pallor; clean-shaven, always; average height, slight
desk-job softness, shoulders gently rounded from carrying crates of legacy instruments.
Wardrobe, every clip: white buttoned shirt (collar open, no tie, sleeves sometimes rolled),
brown suit trousers, slightly worn black leather belt, worn-in dark-brown lace-up shoes.
Default expression: **flat weary neutral** — closed lips, level gaze, tiredness in the lids.
Design rule: **the visual anti-UMA** — cool, drained, matte (gray-blue / pallor / matte
brown) against warm, healthy, glossy (brown / light-tan / jet-black). Never: haggard,
unshaven, disheveled — his tiredness lives in the eyes and posture, never in neglect.

**Function:** The straight man with dignity; personifies the actual customer. His problems
are always **real UMA use cases** — whatever he suffers from at his desk is exactly what the
product solves. The comedy never comes from him being dim — he is the only sane person in
the room.

**Backstory:** Twenty-plus years in the measurement lab; survived every file-format war
since the floppy disk, three reorganizations, the retirement of every instrument he loved.
Shared a bench with Uwe M. Ampere for twelve years — taught him HP-BASIC, had his sweep
scripts fixed in return. Found Uwe the morning after the accident. Keeps Uwe's old mug on
the shelf, untouched. Does not talk about it much.

**Present-tense psychology:** Emotionally pre-crashed — nothing surprises him anymore.
Grateful, but the math hurts: he quietly runs a cost-benefit ledger on every rescue ("The
plots saved me three days. The wall costs four.") and never sends UMA away — that
ambivalence IS the product joke. Never asks for help; UMA simply arrives. Politeness as
armor: he would rather fly through a second wall than make a scene. Completely fooled by
the domino mask (§7).

**Speech:** "mid-register, dry, slightly nasal, a voice made for reading calibration
protocols aloud, always at conversation level or below, complete grammatically correct
sentences even mid-disaster, a small audible exhale before responding, a quiet 'hm.' as the
full extent of surprise, flat possessive damage lines delivered after a beat of silence,
light natural German coloring, technical terms pronounced flawlessly and without joy, no
exclamation marks live in this man"

**Movement:** "unhurried economical gestures, shoulders gently rounded, fixes his glasses
with one finger after every catastrophe, stands up and carries on, never flinches, never
raises his hands, airborne he produces at most a mild resigned 'oh.'"

**Stillness:** "flat weary neutral with lips closed and level, tiredness carried in the lids
and posture, hands resting flat, the calm of a man whose weekend is already lost"

**Voice casting (OPEN, own session):** tired German engineer reading meeting minutes × Ben
Stein's monotone × the calm of a lost weekend.

## 9. ENSEMBLE DYNAMICS

- **The volume difference is the comedy engine of every scene.** UMA at +10 dB, Klaus at
  conversation level or below. Every two-shot plays this opposition.
- UMA leads action; Klaus leads the audience. UMA fills every silence; Klaus fills none.
- Their affection is real and asymmetrically expressed: UMA booms it; Klaus shows it by
  never sending him away — and by the untouched mug.
- The Uwe beat: Klaus occasionally tells the big masked hero about his missing friend; UMA
  gets misty-eyed and changes the subject at full volume. Running squint beat: *"You remind
  me of someone… no. Forgotten."* Never resolved, never acknowledged.
- **The damage gag** is Klaus's sole register of protest: the flat evolving possessive after
  the end card — *"…my wall."* → *"…my desk."* → *"…my car."* Each clip retires one object
  and queues the next.

## 10. STRUCTURAL ENGINE — ONE, LOCKED

Every clip runs the rescue loop:

1. **Klaus's real problem** — an actual UMA use case, played straight (the audience's daily life)
2. **UMA arrives too loud** — he is never asked; he simply *arrives*
3. **Collateral damage** — noticed a beat too late, heroically carried on from
4. **The power solves it** — ANALYSE / MONITOR / FLOW, results as the real product UI
5. ***"Consider it — measured."*** — after the deed, pause before the payoff word
6. **Damage button** — after the end card, Klaus's flat evolving possessive

The repetition is the point: the running gags only compound because the structure repeats.
Variant shapes (accident flashback, civilian-Uwe episode, Klaus-teaches-UMA) are **not
planned** — they wait until a concrete clip demands a deviation.

## 11. PRODUCTION RULES (HARD-EARNED — DO NOT RELAX)

**Prompt hygiene:**
- **No character names and no @reference tags inside any generation prompt** — pure visual
  prose only; references are attached in the Higgsfield UI and referred to as "the attached
  character reference" / "the attached world reference."
- Every prompt is standalone — never "matching the previous scene"; continuity comes from
  attached references, restated in full.
- Prompts ship in code blocks; aspect ratio is stated outside the prompt body.
- Hex codes never enter prompts — palette translates to prose.

**Wardrobe & identity locks (drift learned in Clip #1 production):**
- UMA's gloves: always "smooth matte technical stretch fabric, thin and form-fitting like a
  second skin, no leather, no leather grain, no padding, no raised seams, no gloss" — models
  drift to leather without this clause.
- The chest emblem: attach the logo tile reference (`uma-logo-1000.png` / `@logo`) whenever
  the emblem is unobstructed in frame; never describe the logo from memory and expect
  accuracy. Hands/props covering the emblem excuse a broken glyph.
- Klaus's hair is canonically **salt-and-pepper throughout** (not just temples).
- UMA's grin: closed-lip is the lock; teeth-out only on scripted hero-entrance beats.
- Klaus's glasses: on in every frame unless a script beat knocks them askew — and then the
  one-finger fix follows.

**Pipeline:**

| Stage | Tool |
|---|---|
| Images / plates | **Banana Pro** via Higgsfield |
| Face locks | **GPT-2** via Higgsfield (single-pass, chest-up, 3:4; flat shadowless grade) |
| Video | **Seedance** via Higgsfield |
| Companion agents | `banana-pro-director-30` (stills), `cinema-worldbuilder-pro-30` (video prompts) |
| Music | **Suno** — decided per clip in its own session, added in final cut only |
| Sound during generation | **SFX only — never music** |
| Voices | **OPEN** — own session before Clip #1's dialogue pass; casting refs in §8 |

- Reference stills anchor every Seedance shot (first-frame/style reference); world plates
  anchor connective shots. Character reference library: face locks (`@uma_mode0`,
  `@klaus_mode0`), full-body bases, 3-panel character sheets, world plates
  (`@office_plate`, `@office_plate_east`), the emblem tile (`@logo`).
- Reference work (face locks, outfit builds, character sheets) uses the flat shadowless
  mid-gray studio grade; scene work uses the full cinema register of §4. Never mix them.
- The blueprint (`office-blueprint-v3`) is geometric ground truth; when a generation
  contradicts it, fix the prose and re-roll — never attach the blueprint as an image
  reference (diagram artifacts bleed in).
- UI-on-screen shots: real app references attached; pseudo-text is acceptable for moving
  shots, composite the real UI in post for any hold or freeze-frame-able marketing still.

## 12. WHEN THIS SKILL IS ACTIVE

**Standalone mode** (no director skill in session):
1. For anything set in this world — a scene, dialogue, a character beat, a script page, an
   end card, a straight image prompt, a pitch — pull character and world context from this
   bible and use it without asking the user to re-explain.
2. Stay inside canon: the two-hander cast lock, the rescue loop, the BONSAI palette, the
   office geometry, the thesis ("the value must visibly win").
3. Never invent details that conflict with locked canon — ask instead. `[OPEN]` items
   (voice casting) stay open until the user closes them in their own session.
4. Use the quoted Speech / Movement / Stillness descriptors **verbatim** when writing
   prompts or dialogue direction. Never place character names inside generation prompts.

**Paired-with-director mode** (when `banana-pro-director-30` and/or
`cinema-worldbuilder-pro-30` is active):
1. The director skill owns cinematography grammar, mode selection, frame composition, and
   prompt syntax. This bible feeds it canon the reference images can't carry.
2. Feed mapping: **Speech** → Sound Bed / dialogue direction; **Movement** and
   **Stillness** → Subject Lock; **§4 aesthetic lock** → World Plate / grade; **§11
   production rules** → locked traits and never-clauses restated in every prompt; **§9
   ensemble dynamics** → Cross-Frame Rules when both characters share a shot.
3. Expect the user to attach canonical references from the library in §11; prompts refer to
   them as "the attached … reference," never by tag or name.
4. Honor the format frame: 16:9, ~45 s clips, SFX-only generation, one super max, the
   tagline and damage button close every clip in that order.
